## 📌 Selected Project

### 🧠 Customer Intelligence Platform

**Python · Machine Learning · Generative AI · AWS · FastAPI**

An end-to-end customer intelligence solution that uses transaction data to identify customers showing signs of inactivity.

### Project Scope

| Area | Implementation |
|---|---|
| 📊 Data | Transaction cleaning, validation and customer-level feature engineering |
| 🤖 Machine Learning | Temporal problem definition and comparison of classification models |
| 📈 Risk Scoring | Customer inactivity probability and risk classification |
| ✨ Generative AI | AI-generated customer intelligence using Amazon Bedrock |
| 🔌 API | FastAPI REST prediction and intelligence endpoints |
| 🐳 Engineering | Docker, automated testing and CI |
| ☁️ Cloud | AWS ECR and ECS/Fargate deployment |
